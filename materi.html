Pengertian Komputasi Awan (Cloud Computing)

Komputasi awan (Cloud Computing) adalah model penyediaan sumber daya komputasi seperti server, penyimpanan data, basis data, jaringan, dan perangkat lunak secara sesuai permintaan (on-demand) melalui jaringan internet. Pengguna tidak perlu membeli maupun merawat server fisik secara mandiri, melainkan cukup mengakses layanan yang dikelola oleh penyedia cloud (Cloud Service Provider).

Model Layanan Komputasi Awan

Berdasarkan tingkat kendali pengguna terhadap infrastruktur, layanan cloud dibagi menjadi tiga model utama:

SaaS (Software as a Service)

Perangkat lunak siap pakai yang berjalan sepenuhnya di cloud dan diakses melalui browser tanpa instalasi lokal.

Contoh: Google Workspace (Docs, Forms, Sheets, Drive), Gmail, Zoom.

PaaS (Platform as a Service)

Lingkungan pengembangan dan deployment yang memungkinkan pengembang fokus pada kode aplikasi tanpa mengelola sistem operasi atau server fisik.

Contoh: GitHub Pages, Vercel, Heroku, Google App Engine.

IaaS (Infrastructure as a Service)

Penyediaan infrastruktur komputasi dasar (mesin virtual, penyimpanan, dan jaringan) dengan kendali penuh atas sistem operasi.

Contoh: Amazon EC2 (AWS), Google Compute Engine, Microsoft Azure VM.

Manfaat dan Risiko Layanan Cloud

Manfaat Utama

  • Aksesibilitas Tinggi: Data dan aplikasi dapat diakses kapan saja dan dari perangkat mana saja selama terhubung ke internet.
  • Efisiensi Biaya: Mengurangi belanja perangkat keras fisik (CAPEX) dan beralih ke biaya operasional yang fleksibel.
  • Skalabilitas & Ketersediaan: Kapasitas server dapat ditingkatkan dengan cepat dan didukung infrastruktur pusat data yang aktif 24/7.

Risiko yang Perlu Diwaspadai

  • Ketergantungan Koneksi Internet: Layanan tidak dapat diakses apabila jaringan internet terputus.
  • Keamanan & Privasi Data: Kesalahan pengaturan izin akses (misalnya repositori publik atau link terbuka) dapat mengekspos data sensitif.
  • Vendor Lock-In: Ketergantungan pada arsitektur satu penyedia layanan sehingga pemindahan sistem memerlukan penyesuaian teknis.
